# November 2026 lesson refresh review

All 11 lessons retain their class assignments, release/due dates, two checks per stage, accepted-answer variants and fresh retries. New IDs keep prior work attached to the old definitions. The original rubric standards remain; the repair lesson adds an equivalent fictional workshop context. All final tasks remain distinct from their worked examples.

Timing estimates include reading checks and source cards, thinking, writing and one revision; they are planning allowances, not student timers. The 12-minute lessons budget about 4 minutes for reading/models, 3 for guided action/comparison, 3 for the final and 2 for revision. Bibliography, quotation analysis and argument allow 15 minutes: about 5 for reading/models, 4 guided, 4 final and 2 revision. Student action therefore has 8 or 10 minutes. Repeated errors and individual language needs can extend these estimates.

| Lesson | Common case and evidence/explanation | Student action and missing move | Fresh retry decision |
| --- | --- | --- | --- |
| Bibliography | Signed web essay; each MLA element answers a reader’s retrieval question | Assemble the entry; supply the summary, then credibility/use | New source details, same ordering or assessment decision |
| Quotation analysis | A phrase completes the writer’s sentence; “locked gate” paired with its barrier effect | Embed an editor’s phrase; supply commentary between a given lead-in and thesis link | New quoted image, same integration/interpretation decision |
| Argument | One claim, detail and reason; the model links a specific fact to a proposal | Write a debatable claim; supply the missing bridge, then respond to an objection | New evidence or concern, same reasoning move |
| Advertising evidence | An offer’s actual verb; funding distinguished from control | Supply the unsupported conclusion; explain a printer’s request | New offer, same limit on inference |
| Advertising objection | A reader’s concern tied to a policy clause | Supply one boundary; qualify award sponsorship | New policy objection, same actionable qualification |
| Advertising audience | Fixed newspaper facts answer two readers’ different questions | Complete the explanation for a subscriber; write the critic’s opening | New reader, same relevance decision |
| Ethics: reasons | One practice and one win; observation distinguished from causal claim | Supply a missing limit, then a reason for a trial | New situation, same observation/generalization/comparison decision |
| Ethics: options | Full shelves and an empty partner chair; a measure follows the partner’s request | Supply a success measure; complete one comparison on uninterrupted time | New community task, same shared-measure or trade-off decision |
| Ethics: perspective | Coach and runner give competing reasons for fairness | Supply the teammate’s reason; state a judgment and its informing commitment | New speaker, same fair-account or influence decision |
| Ethics: repair | Torn poster; controlled action paired with impact | Supply impact; add the missing affected-person check | New harm, same ownership/check/prevention decision |
| Ethics: leadership | Invite a real choice; a used design detail demonstrates influence | Complete an invitation; propose an adjustment tied to an observed failure | New response, same observation or responsive-adjustment decision |

Each first stage now has a human problem, with humour or a memorable mistake immediately clarified in prose. New visual captions explain the literal principle and limits of metaphors; images do not carry essential text. The final-feedback prompt asks for an evidence-based comparison with the prior assessed attempt. Delayed checks retrieve the principle using fresh material.

Verification uses fixture responses, not real student work or live OpenRouter calls. ImageGen was used for the illustrations. Images were inspected together and the quotation lesson was checked in the actual local practice player; the builder’s expanded review was checked in a local fixture preview.
