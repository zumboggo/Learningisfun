# Public Ethics adventures

Share `/Learningisfun/#/ethics`, or `/Learningisfun/#/ethics/the-grain-we-keep` and `/Learningisfun/#/ethics/the-measure-that-changed`. These routes require no account and submit no episode progress or grades. Progress stays in component memory and resets on leaving/reloading. They use the normal accessible Story 2 player without studio debugging controls.

Public scripts live in `stories/public-ethics/`. `node scripts/build-public-ethics.mjs` combines them with the existing validated quiz and historical assets, excludes the recurring classroom cast/background, and supplies public source notes. Rebuild the two ZIPs with `scripts/story-package.mjs zip`; the public-ethics tests check ZIP parity. `npm run build` checks that generated JSON matches its sources. Classroom packages and published attempts remain unchanged.

Editorial plan: discover a warm stone → choose to enter → face an immediate distribution problem → make the existing consequential choices → leave accountable arrangements → return safely to the path. The original choices, immediate reactions and variable callbacks remain intact. The return reflects costs rather than awarding moral virtue. Neither edition contains a school, named teacher, death/rebirth framing or class assignment metadata.

Teacher framing includes age guidance, approximate duration, content context, pair/projector use, contrasting-route discussion and three questions per story. All historical events and dialogue are explicitly fictional, with museum references for background. No new historical quotations or curriculum claims were added.

The public player now begins with a full-page white prologue after its fiction notice. The invitation types once, supports immediate reveal and reduced motion, and offers both picking up and leaving the stone. Declining permits reconsidering or exiting without a quiz. Picking up replays the package's introductory narration to the first village scene; normal state, resource totals and story history are retained. A 2.4-second widening aperture reveals the actual stage once and blocks story input until it finishes. Restart remounts the prologue; leaving cleans up typing/reveal timers. Portable packages keep the same short narrated prologue; the interactive white-screen presentation belongs to the public web player.
