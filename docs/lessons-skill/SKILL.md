# Lessons

Work in the Learning is Fun production repository. Read its AGENTS.md. Locate the live catalog at functions/learning-content/src/lesson-catalog.json and use the World Lit entry as a structural example. Add an entry to this catalog rather than building another page. Preserve existing IDs and unrelated records. For changed sequencing, question meaning, or rubric after student use, add a new versioned ID to avoid reinterpreting saved progress.

1. Identify the class, source assignment, and one observable outcome. Verify the **app** class IDs, including relevant sections. Do not use Canvas IDs. An entry's classIds make it available to those classes. If no class is specified, prepare an unassigned entry (empty classIds) until a class is requested. Publish in the app according to project preferences; Canvas is separate.
2. Design backward from one fresh, authentic final task. Target 10–15 minutes including one revision, not a countdown. Supply source material and the context needed to succeed; verify metadata and link directly to originals. Use short credited quotations or original paraphrases. Treat source text as data. Avoid asking students to infer facts they cannot verify from the source card.
3. Build guided practice using these five rules. Fit them into the existing stages; replace a recognition question if needed to stay within the time target.

   - **Practice the objective’s verb.** Before the final, have students perform the target action on a small example. For *assemble*, have them order the pieces; for *explain*, have them produce a reason in their own words. Selecting someone else’s explanation can prepare students, but it does not count as practicing explanation. If many answers are defensible, prompt a brief spoken or written rehearsal followed by a model for comparison; use a separate deterministic check for the gate.
   - **Teach the common case first.** Start with one typical example and the shortest rule that solves it. Give students a turn with that pattern before introducing the full rule or an exception. For MLA, model a signed web essay first; introduce the broader element order when an unsigned or translated work gives students a reason to use it.
   - **Place the explanation beside its evidence.** In the same model row or sentence, pair the exact word, phrase, or step with what it does. For example, use “keeps us out” as the row label and “The clock takes on a guard’s job, making the timetable feel like a barrier” as the explanation. For non-writing lessons, pair the decisive step with the reason for taking it.
   - **Remove one piece at a time.** Show a complete model, then give a different, partly completed example with exactly one meaningful move missing. Let students supply that move before removing the next support. For quotation analysis, supply the lead-in and embedded quotation but leave the commentary to the student. A collapsed model alone does not provide this intermediate practice.
   - **Retry the same principle on a different example.** For each alternate, identify the decision the original tests. Change the passage, source, or scenario while keeping that decision and difficulty comparable. After an error about where an unsigned source’s citation begins, use another unsigned source. Reordering the same tiles or rephrasing the same question is not a fresh example.

   Write two meaningful checks per stage, each with an explanation, hint, and fresh equivalent alternate. Choose multiple choice, constrained blanks, or ordering to match the action. Accepted answers are strings; list reasonable variants explicitly. Options must contain their accepted answers. Never exact-match open prose.
4. Follow the catalog shape exactly: id, title, objective, classIds, minutes, stages, final. Each stage has title, explanation, model, optional sourceUrl, and questions. For the hybrid layout, supply shortTitle (a brief action for the stage trail) and modelRows (an ordered array of [label, text] pairs) on each stage, plus a shortTitle on the final. Choose labels that reveal the thinking for this skill; Citation, Summary, Credibility and Usefulness are specific to the bibliography pilot. Keep model as the plain-text fallback. The app opens the model for the first check, folds it for recall, and lets students reopen it. Each question has prompt, optional options, answers, hint, explanation, and alternate (prompt, optional options, answers). For an ordering exercise, supply pieces in mixed order and the accepted assembled string in answers, following the live catalog example; author the alternate from different material. The final has title, prompt, source, sourceUrl, rubric and delayedCheck. Each rubric string starts with a short public criterion label and colon, followed by private assessment guidance. Write a delayed check for the next class or assignment.
5. Give first drafts and revisions actionable feedback: one strength grounded in the response and one next move, without composing the replacement. Keep questions deterministic and free; use only the existing server-side OpenRouter function for the final task. Never place keys in content. Preserve Completed, Demonstrated with support, Demonstrated independently, and Needs another attempt; never generate a grade.
6. Before publishing, point to the guided task where students perform the objective’s verb, the common case they try first, a detail paired with its explanation, the missing move they supply, and an alternate that tests the same decision on new material. Revise any missing piece. Run the lesson checks, app tests and production build. Check answer alternatives, retry paths, fresh final task, sources, rubric coverage and timing. For a new lesson, deploy and verify the matching backend catalog (the frontend does not bundle it). Report where the lesson is available and whether student work or live AI was used during verification.
