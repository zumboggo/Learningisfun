# Create episode character

Follow [the shared character standard](character-standard.md) for appearance options, anatomy, timing, the reusable creation prompt and verification. Follow [the acting library](acting-library.md) for the closed cue vocabulary. Use `cartoon-v1` for new articulated characters; the studio includes Lin, Mr. Hepting, Mei and Yeyul. Ordinary supported identities need only a versioned character pack, not new animation code.

Maintain `teen-v1` raster packs only when revising legacy artwork. Preserve their exact 13 parts, joint overlaps and neutral fallback. Do not migrate published versions or saved attempts. Static supporting characters may use aligned full-body WebP expression images; missing expressions fall back to neutral. Static images support whole-character movement but not articulated gestures.
